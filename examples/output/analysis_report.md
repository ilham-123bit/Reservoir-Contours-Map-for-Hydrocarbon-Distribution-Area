# Synthetic structural-contour analysis report

## Dataset and quality

Input: `data/synthetic/synthetic_surface.csv`. This is a fictional synthetic depth surface generated by this project. The grid has 101 x-nodes by 91 y-nodes, spacing 100.000 m (x) and 100.000 m (y), 97.99% valid nodes, and 97.64% triangulated mesh coverage. Missing depth nodes remain excluded from contour regions; mesh triangles with any missing vertex are omitted.

## Synthetic geometric results at the selected threshold

The analysis assumes larger numerical depth values are shallower. The synthetic input happens to use negative metre values; negative values are not required for other supported inputs. The raw-grid crest, the maximum valid value in the unsmoothed input, is at (4700.0, 4700.0) m with depth -2261.590 m.

The selected depth threshold is -2321.590 m. It is a scenario parameter used to identify the 8-connected threshold region on the normalized smoothed surface at the raw-grid crest location; it is not necessarily a geologically interpreted spill point. Raw-crest relief is the arithmetic difference between the raw-grid crest depth and the selected threshold (60.000 m).

The smoothed-surface maximum is at (4700.0, 4700.0) m with depth -2264.604 m. It may differ from the raw-grid crest and is the starting node for the grid-exit saddle calculation. The grid-exit saddle is at (600.0, 7200.0) m with smoothed depth -2344.559 m. It is the bottleneck point along the maximum-bottleneck 8-neighbour path from the smoothed-surface maximum to the model-domain edge. This computed saddle is domain dependent; it is not an independently interpreted geological spill point or hydrocarbon contact. The selected threshold contour and grid-exit saddle are distinct quantities.

Area is integrated over a piecewise-linear triangular mesh constructed from the normalized smoothed surface. Each triangle is clipped at the selected depth threshold, and clipped areas are summed only for valid triangles associated with the crest-connected threshold region. Triangles containing any missing depth node are excluded. The resulting area is an approximation based on grid resolution, smoothing, threshold choice and missing-data coverage, not a polygonized geological boundary. The computed area is 19319808.9 m² (19.319809 km²); geometric status: **closed**.

## Threshold sensitivity

Tested 6 selected depth thresholds. Across scenarios classified as closed, estimated area spans 7.425–23.082 km². Rows marked `boundary_limited` reach the model boundary and do not represent fully enclosed regions. See `spill_sensitivity.csv`, `closure_area_sensitivity.png`, `structural_relief_sensitivity.png`, and `closure_scenarios.png`.

## Controlled robustness experiments

- Smoothing: estimated closure area ranges 19.241–19.330 km² across the tested scenarios.
- Missing data: estimated closure area ranges 16.765–19.694 km² across the tested scenarios.
- Resolution: estimated closure area ranges 21.223–21.239 km² across the tested scenarios. The resolution experiment uses a zero-noise surface to isolate sampling. Missing-data and smoothing experiments use fixed seeds; valid-mesh coverage can change because triangles touching missing depth nodes are excluded. See `robustness_scenarios.csv` and `robustness_comparison.png`.

## Assumptions and limitations

All values and figures in this report are synthetic. The raw-grid crest is the maximum valid input node; the smoothed-surface maximum is a separate point used to start the grid-exit saddle path. Threshold regions use the normalized smoothed surface and 8-neighbour connectivity while retaining the original missing-depth mask. Area is an approximation from fixed-diagonal, piecewise-linear triangles clipped at the selected threshold; triangles with missing depth nodes are excluded. Area depends on grid resolution, smoothing, threshold choice and missing-data coverage. Boundary-limited regions are not fully enclosed closures. The grid-exit saddle depends on model extent, sampling and smoothing. Neither a closure-shaped high nor any calculated metric establishes hydrocarbon charge, seal integrity, reservoir quality, accumulation, reserves or commercial viability.
